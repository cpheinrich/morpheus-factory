# sub2api PoC — runbook

Status: working proof of concept, 2026-10-31.

## What this is

A single-machine deployment of [sub2api](https://github.com/Wei-Shaw/sub2api)
(an AI subscription → API gateway) running in **simple mode** on `zoe-mac-mini`,
with two personal subscriptions registered behind it:

| Subscription | sub2api account | Group | API key (name) |
|---|---|---|---|
| Claude (Pro/Max) | `claude-max` (Anthropic OAuth) | `anthropic-default` | `claude` |
| ChatGPT/Codex (Pro) | `codex-pro` (OpenAI OAuth) | `openai-default` | `codex` |

The gateway exposes OpenAI- and Anthropic-compatible endpoints. A client
(Claude Code, Codex CLI) points its base URL at this machine and authenticates
with an `sk-` key; sub2api routes to the right subscription account.

This is deliberately **not** wired into morpheus-factory yet. Factory's broker
port (`src/brokers/`) expects a stable `/factory/v1/capacity` document that a
small adapter would publish from sub2api — that integration is a later step if
this PoC holds up.

## Architecture

```
MacBook Air (main device) ──tailnet──▶ zoe-mac-mini (this machine)
  Claude Code ──ANTHROPIC_BASE_URL──▶ sub2api :8080 ──▶ claude-max (Anthropic)
  Codex CLI   ──OPENAI base_url──────▶ sub2api :8080 ──▶ codex-pro  (OpenAI)
```

- sub2api runs in Docker (via Colima) on this machine, bound to `0.0.0.0:8080`.
- It is reachable over the tailnet at `http://100.76.97.7:8080` or
  `http://zoe-mac-mini.tail7476d9.ts.net:8080` (both verified HTTP 200).
- Traffic is plain HTTP at the app layer; the tailnet's WireGuard layer
  encrypts it in transit. No TLS is configured (fine for a PoC; revisit before
  anything leaves the tailnet).

## Deployment

The deployment lives **outside** the repo (it holds secrets):

```
~/sub2api-deploy/
  docker-compose.local.yml   # refreshed from upstream by the setup script
  .env                       # secrets (admin password, JWT, DB/Redis passwords)
  data/ postgres_data/ redis_data/
```

Reproduce it with:

```sh
scripts/setup-sub2api.sh            # idempotent; preserves .env and data
```

Key settings in `.env` (generated by the script):

- `RUN_MODE=simple` — hides SaaS/billing, skips balance checks.
- `SIMPLE_MODE_AUTO_CREATE_DEFAULT_GROUPS=true` — seeds `anthropic-default`,
  `openai-default`, etc. on startup.
- `TZ=America/Los_Angeles`.

Admin UI: `http://localhost:8080` (login `admin@sub2api.local`; password is in
`~/sub2api-deploy/.env`). The admin account was created by auto-setup on first
run.

## Client configuration

The keys are in the sub2api admin UI (API Keys → "Use Key"). They are **not**
committed here. Substitute `<BASE>` with the tailnet origin
(`http://zoe-mac-mini.tail7476d9.ts.net:8080`) and the real `sk-` values.

### Claude Code

`~/.claude/settings.json`:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "<BASE>",
    "ANTHROPIC_AUTH_TOKEN": "sk-…",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  }
}
```

### Codex CLI

`~/.codex/config.toml`:

```toml
model_provider = "OpenAI"
model = "gpt-6.1-sol"
review_model = "gpt-6.1-sol"
disable_response_storage = true
network_access = "enabled"

[model_providers.OpenAI]
name = "OpenAI"
base_url = "<BASE>/v1"
model_catalog_url = "<BASE>/v1/models"
wire_api = "responses"
requires_openai_auth = true

[features]
api_key_model_discovery = true
goals = true
```

`~/.codex/auth.json`:

```json
{ "OPENAI_API_KEY": "sk-…" }
```

A helper that writes these files for a given base URL and keys:

```sh
scripts/configure-client.sh <BASE> <CLAUDE_KEY> <CODEX_KEY>
```

## Verified

- `GET /health` → 200 (localhost, tailnet IP, and MagicDNS name).
- Anthropic `POST /v1/messages` with the `claude` key → real completion
  (`claude-sonnet-4-5`).
- OpenAI `GET /v1/models` with the `codex` key → 200.
- OpenAI `POST /v1/responses` with the `codex` key → real completion
  (`gpt-6.1-sol`).

## Gotchas

- **`gpt-5.5` is retired.** The Codex "Use Key" dialog defaults to `gpt-5.5`,
  which OpenAI retired from Codex-with-ChatGPT on 2026-10-14. Use `gpt-6.1-sol`
  (verified) or another current model (`gpt-6-luna`, `gpt-6.1-terra`).
- **Two Tailscale installs.** A Tailscale.app was installed and then removed;
  its system extension + VPN are orphaned and will be garbage-collected on the
  next reboot. Until then the bare `tailscale status` may report "stopped"
  (the CLI finds the orphaned app daemon's socket). The Homebrew tailscaled is
  the live one — `tailscale --socket /var/run/tailscaled.socket status` shows
  the real state (`zoe-mac-mini` on `cpheinrich@`).
- **Colima, not Docker Desktop.** `docker compose` needed the compose plugin
  (`brew install docker-compose` + `cliPluginsExtraDirs` in
  `~/.docker/config.json`). A reboot also stops Colima; restart with
  `colima start` then `scripts/setup-sub2api.sh`.
- **Terms of service.** sub2api's own README warns that routing subscription
  traffic through a gateway may violate upstream ToS. This PoC uses two
  personal subscriptions in simple mode, which is the operator's call.
